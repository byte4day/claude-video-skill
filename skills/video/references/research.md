# Research contract

## Depth

| Depth | Feeds |
|-------|-------|
| light | Official site + one store/listing |
| medium | + docs/changelog + press + 2–3 motion refs |
| deep | + competitors + community + frame contact sheets in `research/refs/` |

## File specs

### facts.md
- One claim per bullet
- End with `(source: https://…)`
- Separate **Product** / **Audience** / **Proof** sections when useful

### sources.md
Numbered: `1. URL — what we took`

### visual-notes.md
- Palette (hex if known)
- Type / UI chrome
- Character or product silhouette
- Reference films: title, URL, what to steal (pacing, not footage)

### inventory.md
| Asset | Status | Path/URL |
|-------|--------|----------|
| logo | have/need/blocked | … |

### gaps.md
List unknowns. If a gap will appear on screen anyway, tag **illustrative**.

## Parallel feeds

Parent or researcher may spawn `video-feed-scout` with one of: `store`, `press`, `docs`, `assets`, `motion-refs`. Scouts write `research/_feeds/<feed>.md`; researcher merges.
