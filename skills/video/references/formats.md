# Formats

| Format | Goal | Typical length | Notes |
|--------|------|----------------|-------|
| `product-ad` | Desire + CTA | 15–30s | Hero object, one benefit |
| `game-demo` | Play fantasy | 20–45s | Verb first, then systems |
| `app-demo` | UI clarity | 20–40s | Cursor/flow, readable UI |
| `explainer` | Understanding | 30–90s | Steps, captions |
| `logo-sting` | Brand mark | 3–8s | Loop-friendly |
| `sizzle` | Hype montage | 15–30s | Hard cuts, whip energy |

Classify from the brief before storyboarding. Store in `settings.json` → `format`.
