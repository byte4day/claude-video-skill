# Pacing grammar

- **Caption = stop.** If text is on screen, hold long enough to read (~0.3s/word, min 1.2s).
- **One focal point** per scene. Extra ideas become later scenes.
- **Energy arc:** hook (0–15%) → proof/key (15–75%) → CTA (last 15–25%).
- **Game demos:** show the verb (what you do) by ~3s; UI chrome after fantasy.
- **Product ads:** object hero early; one benefit; end on name + CTA.
- **Transitions:** hard cuts for energy; crossfades for editorial; whips for sizzle.
- Prefer fewer scenes with clear holds over many flash cuts unless format is `sizzle`.
